# SQL Server DBA Lab

Laboratório prático desenvolvido para estudo e aplicação de conceitos de administração de bancos de dados utilizando SQL Server 2025 Developer Edition.

## 🎯 Objetivo

O objetivo deste projeto é simular atividades presentes na rotina de um DBA, documentando não apenas os comandos utilizados, mas também os problemas encontrados, o processo de diagnóstico e as soluções aplicadas.

## 🛠️ Tecnologias

- SQL Server 2025 Developer Edition
- SQL Server Management Studio (SSMS)
- T-SQL
- Windows

## 📚 Conteúdo do laboratório

O projeto abordará:

- Configuração inicial da instância
- Gerenciamento de memória
- Arquivos MDF e LDF
- Recovery Models
- Transações
- Blocking e troubleshooting
- Dynamic Management Views (DMVs)
- Backup FULL
- Backup Differential
- Transaction Log Backup
- Restore
- Point-in-Time Recovery
- SQL Server Agent
- Automação de rotinas administrativas
